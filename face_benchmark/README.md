## 撮影ルール

**Enrollment**
1人5枚。正面・通常照明・通常距離・自然な表情という高品質な基準条件で撮影する。同じ画像のコピーではなく5回撮影する。

**Test**
1人16枚。正面2枚＋左右＋上下＋明暗＋片側照明＋逆光＋眼鏡＋眼鏡暗所＋表情2種類＋遠近を撮影する。Enrollmentとは別画像で、可能なら別日に撮影する。
**Benchmark**
4人全員について本人比較（Genuine）と他人比較（Impostor）を行い、同じ84枚を buffalo_l → antelopev2 → Japanese_FACE_V1 の3モデルすべてに入力する。
